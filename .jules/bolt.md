## 2024-06-23 - Markdown Component Re-renders
**Learning:** The `Markdown` component in `ghostframe` uses `Streamdown`, which relies on computationally expensive dependencies (`shiki`, `katex`). If static configuration objects like `shikiTheme` (e.g. `["github-light", "github-dark"]`) or `controls` are defined inline or within the component's render body, they generate new references on every parent render cycle, causing referential equality checks to fail and triggering wasteful re-renders. This is particularly problematic in parent components like `ResponseView` that are frequently re-rendered by application state changes (e.g., transcripts updating in `InterviewShell`).
**Action:** Always extract static configuration objects out of the React component's module scope, explicitly typing them if necessary (e.g., `[BundledTheme, BundledTheme]`), and wrap both the parent and target component in `React.memo` to establish an effective re-render shield around the expensive `Streamdown` subtree.
