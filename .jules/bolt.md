## 2025-03-09 - Markdown Component Extraction
**Learning:** The `Markdown` component in `src/components/Markdown/index.tsx` was recreating expensive arrays (like `SHIKI_THEMES`) and objects (like `STREAMDOWN_CONTROLS`) on every render, causing expensive parser recalculations for Streamdown when its parent state changed.
**Action:** Always extract completely static configuration arrays and objects out of the React render loop into module-level variables (especially for expensive dependencies like `Streamdown`/`shiki`). Wrap components in `React.memo` when all their props are primitive strings/booleans to take advantage of shallow equality checks and prevent re-renders when parent states change without affecting this specific component. Use strict type `import type { BundledTheme } from "shiki";` and type `[BundledTheme, BundledTheme]` instead of array inference for TypeScript compliance in `Streamdown` options.
