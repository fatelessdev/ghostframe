## 2024-05-14 - Optimize Markdown component rendering
**Learning:** For computationally expensive React components like Streamdown (which uses Shiki and KaTeX), passing inline object literals (like `shikiTheme={["github-light", "github-dark"]}` or `controls={{...}}`) breaks referential equality on every parent re-render, causing expensive and unnecessary re-evaluations. Furthermore, when extracting `shikiTheme` array statically in TypeScript, it must be typed strictly as a tuple (e.g., `[BundledTheme, BundledTheme]`) rather than an array to resolve TypeScript assignment errors.
**Action:** Always extract static configuration objects and arrays outside of React components before applying `React.memo`, especially for complex markdown renderers, and remember to type Shiki themes as tuples when multiple are used.
