## 2026-05-13 - Markdown Component Memoization\n**Learning:** The Markdown component used in this repository relies on Streamdown, which is computationally expensive. Because React components often re-render when parent state changes, passing inline objects or arrays directly to the Streamdown component defeated any potential memoization, causing wasteful re-renders. We must explicitly extract these static config objects and use React.memo.\n**Action:** Always extract static arrays, objects, and configurations outside of React components, particularly those using Streamdown, Mermaid, Shiki, or KaTeX, before applying React.memo to ensure referential equality across renders.
